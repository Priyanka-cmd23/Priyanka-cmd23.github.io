# Portfolio - Radhika Saxena

Personal portfolio website built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- Dark/Light mode
- Animated sections with Framer Motion
- Responsive design
- Bento grid layout
- Glassmorphism effects
- Project showcase
- GitHub integration
- Contact form

## Tech Stack

- React 19
- TypeScript 6
- Tailwind CSS 4
- Framer Motion
- Lucide Icons
- Vite
